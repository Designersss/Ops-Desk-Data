# Петро Билдинг Системс — PBS Dashboard

Операционная панель для генерального директора и производственных участков компании «Петро Билдинг Системс».

## Открыть сайт

```bash
git clone https://github.com/Designersss/Ops-Desk-Data.git
cd Ops-Desk-Data
```

Откройте `index.html` в браузере. При необходимости запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Адрес: http://localhost:8080. Установка зависимостей не требуется.

## Страницы

- **Обзор** — ключевые показатели, график, замечания к данным, сводная таблица.
- **Заготовка**, **Потребность сварки**, **Документация** — отдельные рабочие журналы, карточки записей и форма добавления.
- **Качество данных** — замечания и их влияние на связанные показатели.
- **Отчёты** — параметры выгрузки по выбранному периоду.
- **Настройки → Импорт данных** — состояние трёх Excel-источников и интерфейс их загрузки.

Сохранены фирменный логотип PBS, адаптивная светлая тема, сворачиваемое меню, переходы между разделами, выбор периода и окна действий.

## Текущее состояние

Здесь реализованы **HTML, CSS и JavaScript для интерфейса и навигации**. Значения на экранах пока заданы статически. Импорт XLSX, хранение в базе, проверка ошибок, пересчёты и скачивание файлов **ещё не подключены**; действия не изменяют постоянные данные. Это необходимо учитывать при проверке пользовательских сценариев.

После согласования внешнего вида интерфейс будет перенесён на Next.js/TypeScript. Отдельно реализуем постоянное хранение, однократный импорт трёх исходных файлов, работу после удаления Excel, расчёты со строгой проверкой связанных показателей и экспорт CSV/Excel.

## Структура

```text
index.html                 — каркас приложения
styles.css                 — стили и адаптивная сетка
app.js                     — страницы, навигация, диалоги
assets/pbs-logo.webp       — логотип компании
docs/DESIGN_SYSTEM.md      — правила дизайна и структура экранов
```

Старая Python/SQLite-реализация находится в отдельном PR #1 и не входит в текущую ветку разработки интерфейса.

## Детальные страницы записей

В разделах **Заготовка**, **Потребность сварки** и **Документация** каждая строка журнала открывается на отдельном адресе внутри интерфейса, например `#preparation/2`, `#welding/2`, `#documents/0`. Три универсальных шаблона показывают исходные поля из Excel, план/факт или потребность, статус проверки и подтверждённые связи между партиями.

- Навигация: открыть строку → просмотреть детали → перейти к связанной партии или вернуться в журнал.
- «Редактировать запись» открывает форму с полями выбранного участка.
- Все 23 строки представлены в журналах; одинаковые идентификаторы исходных строк не мешают навигации, потому что маршруты используют отдельный индекс записи.
- На текущем этапе сохранение правок и загрузка новых Excel-файлов не подключены: страницы служат для согласования интерфейса перед переносом на Next.js.
- Стили детальных страниц вынесены в `detail.css`, основная утверждённая дизайн-система не изменена.
