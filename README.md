# Петро Билдинг Системс · PBS Dashboard

Визуальный **HTML/CSS/JavaScript-прототип** будущей операционной панели руководителя. Создан как первый этап согласования UX/UI тестового задания Data/AI Analyst при CEO.

> **Это только дизайн-концепция.** Здесь нет Next.js, сервера, базы данных, автоматических расчётов, настоящего импорта или выгрузки. Все цифры и таблицы демонстрационные. Рабочую логику создадим отдельно, после утверждения визуального дизайна.

## Быстрый запуск

После `git clone` или `git pull` откройте **`index.html`** двойным щелчком. Для обычного локального сервера (необязательно):

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080. Никаких `npm install` не нужно. Интернет требуется только для загрузки шрифта Manrope; без него используется системный шрифт.

## Что можно посмотреть

- **Обзор:** 4 KPI-карточки, иллюстративный график, контроль качества, сводная таблица.
- **Заготовка**, **Потребность сварки**, **Документация:** компоновка рабочих экранов, поиск по демонстрационным строкам, карточка и форма добавления записи.
- **Качество данных:** список пяти проблем с макетом детализации и исправления.
- **Отчёты:** макет экспорта по выбранному периоду.
- **Настройки:** основные принципы дизайн-системы.
- Sidebar сворачивается, на мобильных появляется по кнопке меню; есть быстрый переход по `Ctrl/⌘ + K`, всплывающие окна и выбор периода.

Все «сохранения»/«экспорты» показывают только подсказку, **не изменяют данные и не создают файл**.

## Структура

```text
index.html            # Семантическая разметка shell и навигации
styles.css            # Адаптивная фирменная дизайн-система PBS

assets/pbs-logo.webp  # Оптимизированный логотип из предоставленного изображения
docs/DESIGN_SYSTEM.md # Решения и правила UI
```
