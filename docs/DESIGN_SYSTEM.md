# PBS · Система интерфейса

**Компания:** Петро Билдинг Системс / PBS. Фирменный логотип предоставлен компанией.

## Основные принципы

- Строгий, читаемый dashboard для строительной и производственной компании.
- Светлая палитра, аккуратные границы, низкая насыщенность цветовых акцентов.
- Краткая навигация без аккаунтов, уведомлений, глобального поиска и других функций вне задания.
- Никакого искусственного общего процента для независимых участков: заготовка и сварка связаны при наличии однозначного соответствия, документация самостоятельна.
- Ошибки выделяются текстом и цветом; сомнительные показатели не получают статус подтверждённых.

## Навигация

- **Рабочее пространство:** Обзор, Качество данных, Отчёты.
- **Производство:** Заготовка, Потребность сварки, Документация.
- **Система:** Настройки → Импорт данных.

На главной странице: 4 KPI → динамика и проблемы → сводка. В рабочих разделах: заголовок, действие добавления записи, фильтры, журнал, карточка записи. В настройках: текущий состав загруженных источников, количество записей, форма выбора трёх исходных файлов.

## Этап реализации

На данном этапе доступны навигация и визуальные состояния элементов. Данные жёстко заданы в JavaScript. Импорт, сохранение, пересчёты и скачивание файлов будут реализованы на сервере после утверждения интерфейса. Не представлять текущие статические значения как расчёты из базы.
