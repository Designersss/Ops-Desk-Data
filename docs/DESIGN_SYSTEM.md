# PBS · UI Design System v0.1

**Бренд:** Петро Билдинг Системс / PBS. Используется оптимизированное изображение логотипа, предоставленного заказчиком.

## Принципы

- Профессиональная управленческая панель строительной/производственной компании, не декоративный AI/SaaS-интерфейс.
- Светлая тема, читаемые цифры, высокая плотность данных без перегруза.
- На каждом экране один основной акцент; важные проблемы обозначаются не только цветом, но и текстом.
- Независимые участки не смешивать в одном фиктивном «общем проценте».

**Шрифт:** Manrope, системный sans-serif — fallback.  
**Радиусы:** карточки 15 px; кнопки 9 px.  
**Desktop sidebar:** 252 px; свёрнутый 73 px.  
**Header:** 74 px desktop / 65 px mobile.  
**Контент:** горизонтальные отступы 37 px на большом экране, 15 px на мобильных; max-width 1600 px.  
**Адаптивность:** при < 1060 px карточки становятся 2 × 2; при < 760 px sidebar становится overlay.

## Информационная архитектура

- Рабочее пространство: Обзор, Качество данных, Отчёты
- Производство: Заготовка, Потребность сварки, Документация
- Сервис: Настройки

**Dashboard**: 4 KPI → график и проблемы → сводная таблица → методологическое пояснение.  
**Рабочие страницы**: название → действие добавить → журнал → детали записи.  
**Взаимодействия**: sidebar, hash-навигация, поиск/горячая клавиша, селектор периода, демонстрационные модальные окна.

## Граница прототипа

Все табличные строки, динамика графика и визуальные счетчики заданы явно в коде. Пользовательские правки **не сохраняются**. Никаких backend/API/Excel-операций. После утверждения статические примеры заменяются проверенными вычислениями из единого источника данных.
